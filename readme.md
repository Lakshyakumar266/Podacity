# Podacity

A podcast website built with Flask that allows users to discover, stream, and manage their favorite podcasts in one place.

## What It Does

Podacity is a web-based podcast platform that provides:
- Browse and discover podcasts across different categories
- Stream podcast episodes directly in your browser
- Search for your favorite shows and episodes
- Clean and intuitive user interface for easy navigation

## Why Use Podacity?

- **Simple & Fast**: Lightweight Flask application with quick load times
- **All-in-One Platform**: No need to switch between multiple apps
- **Easy Access**: Access your podcasts from any device with a browser
- **Open Source**: Free to use and modify
  
## Tech Stack

- Python
- Flask

## How to Run

### Prerequisites
- Python 3.7 or higher
- pip (Python package manager)

### Installation & Setup

1. **Clone the repository**
```bash
git clone https://github.com/Lakshyakumar266/Podacity.git
cd Podacity
```

2. **Create a virtual environment (recommended)**
```bash
python -m venv venv

# On Windows
venv\Scripts\activate

# On macOS/Linux
source venv/bin/activate
```

3. **Install dependencies**
```bash
pip install -r requirements.txt
```

4. **Run the application**
```bash
python app.py
```

5. **Open your browser**
Navigate to `http://localhost:5000` or `http://127.0.0.1:5000`

### Troubleshooting

If you encounter any issues:
- Make sure Python 3.7+ is installed: `python --version`
- Ensure all dependencies are installed: `pip install -r requirements.txt`
- Check if port 5000 is available or modify the port in `app.py`
